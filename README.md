# Data Analysis Portfolio

Portfólio de projetos desenvolvidos com foco em **Análise de Dados, Business Intelligence e Automação**.

## 🛠️ Tecnologias

- Python
- Pandas
- SQL
- PostgreSQL
- Power BI
- Excel

## 📊 Projetos

### 1. Análise de Vendas
**Status:** Em desenvolvimento

Projeto de análise exploratória de dados de vendas utilizando Python e Pandas.

Principais etapas:
- Limpeza e tratamento dos dados
- Análise exploratória
- Criação de indicadores
- Identificação de padrões e tendências
- Geração de insights

### 2. Dashboard de BI
**Status:** Planejado

Projeto utilizando SQL e Power BI para análise de indicadores de negócio.

### 3. Automação de Relatório Mensal
**Status:** Planejado

Automação de tratamento e atualização de dados utilizando Python e Excel.

## 🎯 Objetivo

Desenvolver projetos práticos que demonstrem habilidades em análise, tratamento, visualização e automação de dados.
